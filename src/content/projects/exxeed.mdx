## Overview

Exxeed is a desktop app for iRacing that tells you **where** to brake, in terms
you can see out of the windscreen, at the moment you need to hear it.

```
"Brake at the hundred board"    → spoken so it ends about a second before the braking point
"Gas when you see the ferris wheel"
"Stay inside for the next one"
```

It is the co-driver idea from rallying, applied to circuit racing and driven by
live telemetry. A set of callouts for one track and car is a **callout pack**.
You can write one, import one from a YouTube track guide, or install one another
driver has shared.

## Why this doesn't already exist

The telemetry coaches that exist today compare your lap against a reference and
report the difference: *"brake 10 metres later."* That is useful once you already
know roughly where to brake. On a track you have never driven, it is advice about
a decision you do not yet know how to make.

A reference lap does contain the braking point, but as *"2,340 metres into the
lap"*, which means nothing at 250 km/h. What a driver needs is that distance
turned into something visible: the 100 board, the end of the tyre wall, the
ferris wheel. Today that only exists in YouTube track guides, which you watch,
pause, re-watch, and try to remember three corners at a time.

Exxeed takes both halves. **Telemetry says where** (the precise lap position of
each braking point). **A person, or a track guide, says what to call it.** The
app then speaks it at the right moment.

## The note editor

<div class="not-prose my-8">
  <Image
    src={editorShot}
    alt="The Exxeed note editor: Snetterton with numbered callouts, braking zones, and the throttle and brake chart"
    class="w-full rounded-[var(--radius-xl)] border border-[var(--border)]"
  />
</div>

The editor is where a pack is written and checked.

- **The lap, in order.** The list on the left shows each turn with its callouts.
  Hover a callout or a turn and the other side lights up.
- **Where each callout speaks.** The blue arc behind a marker is the stretch of
  track the voice runs over, from where it starts to the callout's point. Orange
  means two callouts overlap.
- **Where the reference lap braked.** Red stripes show the brake on, and a red
  bar marks where braking starts for each corner. A callout can be snapped to it.
- **Throttle, brake and speed** for the whole lap run under the map.
- **Play lap** drives the reference lap around the map at its real speed and
  speaks every callout where the app would, so you hear the lap before you
  drive it.
- **Render audio** turns the text into speech locally with
  [Piper](https://github.com/rhasspy/piper). Nothing is sent to a speech service.

## Track Coach and callout packs

Track Coach lists the packs you wrote and the ones you installed. The app picks
the right one for the track and car when the sim connects. Test mode replays a
recorded lap through the callouts and overlays without the sim.

<div class="not-prose my-8">
  <Image
    src={contentShot}
    alt="The Content tab: a callout pack page with its description, callouts, map and changelog"
    class="w-full rounded-[var(--radius-xl)] border border-[var(--border)]"
  />
</div>

The **Content** tab is where packs are found. Each pack has a page with its
description, the callouts themselves, the map, a changelog, and where it was
adapted from. Packs have versions, so an author can improve one and everyone who
installed it gets the update. Browsing and installing need no account; publishing
and starring need a sign-in (Discord, Google or email).

A pack is small: about 1 KB of text. The audio is rendered on the machine that
installs it, so only the words travel.

## Importing a YouTube track guide

<div class="not-prose my-8">
  <Image
    src={importerShot}
    alt="The YouTube importer, listing this week's official iRacing races"
    class="w-full rounded-[var(--radius-xl)] border border-[var(--border)]"
  />
</div>

1. Pick the race: the live session, one of this week's official races, or type it in.
2. Search for a track guide and watch it beside its transcript.
3. Convert the transcript into one callout per corner with Claude, OpenAI, Gemini
   or a local model, on your own API key. Or copy the prompt into any AI chat and
   paste the answer back.
4. The callouts are placed on the track map, rendered to audio, and opened in the
   editor for review. The pack keeps a credit to the guide it came from.

## Garage 61

<div class="not-prose my-8">
  <Image
    src={garage61Shot}
    alt="Import a lap from Garage 61, with Only my laps ticked"
    class="w-full rounded-[var(--radius-xl)] border border-[var(--border)]"
  />
</div>

Exxeed can build a track map and a reference lap from a lap in
[Garage 61](https://garage61.net), so a driver who already logs laps there does
not have to drive one again just to make a map.

**What it uses.** The documented v1 API: the signed-in driver, the track and car
lists, a lap search, and the lap's telemetry CSV. From that one lap the app takes
position, speed, throttle, brake, gear and steering.

**What it makes.** The positions become the track's centreline and corners. The
other channels are resampled onto a distance grid and become the reference lap
that callouts are timed against and the editor draws.

**How the data is handled.**

- The Garage 61 token is entered in the app, stored encrypted with the operating
  system's keychain, and used only from that machine. It is not in the app's
  code and is never sent to Exxeed's servers.
- **Only the driver's own laps** are offered by default. Teammates' laps appear
  only if the driver unticks that, with a note that the lap is the teammate's to
  share.
- A lap exported as a CSV from the Garage 61 website can be imported with no
  token at all.
- The map and the reference lap built from a lap are shared to Exxeed's database
  when the driver is signed in to Exxeed, so other drivers get a map for that
  track without calling Garage 61. The raw CSV is not stored or shared.
- Requests are few: one lap per track layout, tracks that already have a map are
  skipped, and rate-limit responses are waited out.

## How it's built

```
PREPARATION (offline, slow, AI allowed)
  one lap          ──► track map + reference lap
  YouTube guide    ──► callouts ──► review in the editor ──► audio
                                     │
                                     ▼
DRIVING (60 Hz, no network, no AI)
  telemetry + callout pack ──► when to speak ──► play the clip
```

While you drive, the app only reads what was prepared earlier and plays
pre-rendered audio. That keeps it fast, lets it run offline, and means it can be
tested against a recorded lap instead of a driving session. The AI cost is paid
once per video, never per lap.

The code is a strict TypeScript monorepo. The timing engine is a pure package
with no file or network access, which is how it is tested without the sim.
Sharing runs on Supabase with row-level security from the first migration.

## Status

Alpha. It runs against iRacing on Windows and is developed on a Mac against
recorded laps. Working today: callouts, the editor, YouTube import, Garage 61
import, overlays, accounts, and publishing and installing packs.

Not built yet: a Windows installer, a race summary after each session, themes
for the overlays, and driver profiles with stats. Callouts that go quiet once
you have learned a corner are planned too.
